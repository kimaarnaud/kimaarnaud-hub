Règles générales d'adéquation langage / type de projet
  • TypeScript (Next.js, NestJS, Angular, React Native) : un seul langage du navigateur au serveur, immense écosystème, idéal pour les produits web riches et les équipes full-stack.
  • Python (Django, FastAPI) : productivité, data et IA ; Django pour le « batteries incluses » (admin, ORM, auth), FastAPI pour des API asynchrones et typées.
  • Java / Kotlin (Spring Boot) : robustesse, transactions, écosystème bancaire et institutionnel, microservices matures.
  • Kotlin (Android, KMP), Swift (iOS) : accès natif complet au matériel (GPS, biométrie, HealthKit, arrière-plan) et performances maximales.
  • Dart / Flutter : une base de code pour Android, iOS et web avec UI très personnalisée ; parfait quand plusieurs apps partagent une identité visuelle.
  • Go : services réseau concurrents, binaires simples à déployer, latence faible (billetterie, dispatch, WebSocket).
  • Rust : sécurité mémoire et performance pour l'IoT, l'embarqué et les brokers à forte charge.
  • Elixir / Phoenix : millions de connexions persistantes, tolérance aux pannes (BEAM) : messagerie, présence, temps réel massif.
  • C# (.NET, Unity) : entreprise (ASP.NET Core, SignalR) et jeu (Unity) avec un même langage.
  • PHP (Laravel), Ruby (Rails) : frameworks « opinionated » qui font livrer un back-office complet très vite ; hébergement peu coûteux.
